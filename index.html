01 · PROPÓSITO DEL PROYECTO

Convertir un proceso disperso en un flujo claro y controlado.

ZAVCKI se desarrolló para evitar cotizaciones manuales, cálculos inconsistentes y registros separados de clientes o pedidos. El sistema concentra la información en una sola solución y facilita el seguimiento de cada solicitud.

!

Problema identificado

La creación manual de cotizaciones puede provocar errores en precios, pérdida de datos y dificultad para conocer qué solicitó cada cliente.

◎

¿Por qué se desarrolló?

Para automatizar el cálculo de servicios y extras, registrar clientes, almacenar pedidos y presentar un proceso comercial más organizado.

↗

¿A quién beneficia?

A empresas de desarrollo de software y a sus clientes, ya que ambos pueden trabajar con información más clara, trazable y consistente.

✓

Finalidad

Proporcionar una herramienta capaz de gestionar el proceso desde la selección del servicio hasta el registro y seguimiento del pedido.

02 · OBJETIVOS

Un objetivo general y metas específicas medibles.

OBJETIVO GENERAL

Desarrollar un sistema informático en Java conectado a MySQL que automatice la cotización de servicios de software, el registro de clientes, la gestión de pedidos y su seguimiento, con el fin de organizar la información comercial de ZAVCKI y reducir procesos manuales.

01

Interfaz intuitiva

Diseñar pantallas claras para que el usuario pueda registrarse, iniciar sesión y navegar entre los servicios.

02

Cotización automática

Calcular el precio final según el servicio elegido, opciones adicionales y configuración seleccionada.

03

Persistencia de datos

Guardar clientes, pedidos y detalles de cada solicitud dentro de una base de datos MySQL.

04

Seguimiento

Permitir consultar el estado de cada pedido para conocer el avance del proyecto solicitado.

03 · ALCANCE

Qué hace el sistema y hasta dónde llega.

El alcance se centra en el proceso de cotización y gestión de servicios de software. La aplicación funciona como una herramienta de escritorio construida con Java Swing y conectada a una base de datos.

✓

Incluido en el sistema

  • Registro e inicio de sesión de clientes.
  • Catálogo de productos y servicios tecnológicos.
  • Configuración de servicios y opciones adicionales.
  • Cálculo automático del total de una cotización.
  • Carrito para agrupar servicios seleccionados.
  • Registro de pedidos y detalle de pedido en MySQL.
  • Seguimiento del estado de una solicitud.
  • Validaciones y conexión con base de datos.
—

Límites actuales

  • No procesa pagos bancarios reales.
  • No sustituye un sistema contable o de facturación fiscal.
  • El despliegue principal del prototipo es local.
  • La comunicación externa depende de medios como WhatsApp.
  • Las funciones avanzadas pueden incorporarse en futuras versiones.

04 · CARACTERÍSTICAS

Funciones principales de ZAVCKI.

Los módulos fueron diseñados para que el flujo del cliente avance de forma ordenada desde el acceso hasta el seguimiento del pedido.

01

Registro de clientes

Captura los datos necesarios para relacionar cada pedido con la persona que lo solicita.

02

Inicio de sesión

Valida credenciales antes de confirmar pedidos y protege el acceso a las operaciones del usuario.

03

Catálogo de servicios

Presenta diferentes soluciones de software y permite ingresar al cotizador correspondiente.

04

Cotizaciones dinámicas

Suma precios base, extras y configuraciones para mostrar un total estimado en tiempo real.

05

Carrito de servicios

Agrupa los servicios seleccionados, permite revisar detalles y eliminar opciones antes de confirmar.

06

Pedidos y seguimiento

Guarda la solicitud, asigna un número de pedido y permite visualizar el avance del proyecto.

07

Base de datos

Centraliza clientes, pedidos y detalles para conservar la información entre sesiones.

08

Validaciones

Controla campos, sesiones y condiciones antes de guardar información o ejecutar procesos.
