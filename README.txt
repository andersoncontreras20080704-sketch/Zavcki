ZAVCKI - Página web de presentación del proyecto
=================================================

Contenido de la carpeta:
- index.html                Página principal.
- css/styles.css            Diseño responsive completo.
- js/app.js                 Menú móvil, animaciones, navegación y galería.
- img/                      Logo y recursos visuales del proyecto ZAVCKI.

Cómo abrirla:
1. Abra la carpeta ZAVCKI_Pagina_Web.
2. Haga doble clic en index.html.
3. Se abrirá en Chrome, Edge, Firefox u otro navegador moderno.

Estructura incluida según la guía de certificación:
- Inicio.
- Propósito del proyecto.
- Objetivos.
- Alcance.
- Características del sistema.
- Diseño y arquitectura.
- Prototipo / recursos visuales.
- Tecnologías utilizadas.
- Escalabilidad.
- Información del desarrollador.

La página está adaptada para computadora, laptop, tablet y teléfono.
Para entregar la versión HTML, conserve siempre las carpetas css, js e img junto a index.html.
